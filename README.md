# 익명 신문고 (Anonymous Complaint Board)

이용자가 개인정보 노출 없이 익명으로 불만 및 건의사항을 등록하고, 관리자가 처리 상태를 변경하며 답변을 남길 수 있는 게시판 애플리케이션입니다.

## 주요 기능

- **익명 불만 등록**: 카테고리(`서비스/운영`, `시설/환경`, `시스템/IT`, `기타 건의`) 선택, 공개글/비밀글 설정, 본인 확인용 일회용 비밀번호(`scrypt` 단방향 해시 암호화) 설정
- **비밀글 보호**: 비밀글은 작성 시 설정한 비밀번호를 입력한 본인 또는 로그인한 관리자만 본문과 답변 열람 가능
- **작성자 수정/삭제**: 작성 시 설정한 비밀번호 검증을 통해 본인 게시글 수정 및 삭제
- **관리자 모드**:
  - 관리자 비밀번호(`ADMIN_PASSWORD`, 기본값 `admin1234`)로 로그인
  - 모든 비밀글 즉시 열람
  - 처리 상태 변경 (`접수대기` → `처리중` → `답변완료`)
  - 담당자 답변 등록 및 삭제
- **통계 및 필터링**: 전체/접수대기/처리중/답변완료 현황 대시보드, 상태별·카테고리별 필터링 및 키워드 검색

## 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 데이터베이스 테이블 생성 및 초기 샘플 데이터 시딩
npm run db:push
npm run db:seed

# 3. 개발 서버 실행
npm run dev
```

- 기본 관리자 비밀번호: `admin1234` (`.env` 파일의 `ADMIN_PASSWORD`에서 변경 가능)
- 샘플 비밀글 비밀번호: `1234`
