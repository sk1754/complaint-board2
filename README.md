# 제2공학관 통합 다중 게시판 포털 시스템 (1단계 ~ 4단계 완성본)

제2공학관 공통 공간(`2공학관 공통`)과 4개 학과(**컴전과, 항공과, 메카과, 정통과**)를 아우르는 **실명 기반 다중 게시판·질의응답·운영 관리 포털 시스템**입니다.

> 📄 **개발 상세 설명 및 프롬프트·에이전트 응답 전체 기록**: [DEVELOPMENT_LOG.md](./DEVELOPMENT_LOG.md) 문서에서 확인하실 수 있습니다.

## 1. 단계별 구현된 전체 기능 요약

### [1단계] 기본 게시판 및 실명 회원 인증 구현
- **실명 회원가입 (`/signup`) 및 로그인 (`/login`)**: 아이디 중복 확인, 비밀번호 암호화 저장(`scrypt`), 이름(실명), 소속 학과(`컴전과·항공과·메카과·정통과`) 선택 가입
- **로그인 상태 유지**: `HttpOnly` 세션 쿠키를 통해 페이지 이동·새로고침 시에도 로그인 유지
- **게시글 기본 CRUD 및 권한 검사**:
  - 목록 조회(페이지 나누기), 상세 조회(작성일·수정일 표시), 작성·수정·삭제
  - 필수 항목(제목·본문) 미입력 시 등록 차단
  - **비로그인 작성 차단(`401`)** 및 **타인 글 수정·삭제 차단(`403`)**: 화면 버튼 숨김뿐 아니라 서버 API 요청까지 철저히 검증·차단

### [2단계] 학과별 게시판 분리 및 3단계 관리자 권한 구현
- **학과별 독립 공간**: `컴전과(COMP)`, `항공과(AERO)`, `메카과(MECHA)`, `정통과(INFO)` 4개 학과 게시판 분리
- **학과별 열람 및 작성 정책**:
  - **다른 학과의 글 조회 허용**: 모든 이용자가 타 학과 공지·질문을 열람 가능
  - **질문 작성 범위 제한**: 일반 학생은 본인 소속 학과(또는 2공학관 공통 게시판)에만 질문 작성 가능
  - **공지 작성 제한**: 담당 학과 관리자(`DEPT_ADMIN`)와 전체 관리자(`SUPER_ADMIN`)만 공지 작성 및 **중요 공지 상단 고정** 가능
- **관리자 권한 분리 (`/admin`)**:
  - 사용자 역할을 **일반 회원(`USER`) · 학과 관리자(`DEPT_ADMIN`) · 전체 관리자(`SUPER_ADMIN`)** 3단계로 구분
  - **학과 간 관리 차단**: 컴전과 관리자는 항공과 등 타 학과 게시물을 숨김·삭제할 수 없음(`403` 차단)
  - **전체 관리자 권한 설정**: 전체 관리자만 회원의 학과 관리자 지정·해제 및 담당 학과 변경 가능
  - **내 학과 우선 표시**: 로그인 시 본인 소속 학과 게시판으로 기본 이동

### [3단계] 통합 조회·검색 및 질의응답(Q&A) 상태 관리 구현
- **2공학관 공통 공간 (`COMMON`)**:
  - **공통 공지**: 전체 관리자만 작성 가능하며, 노출 대상 학과(`ALL` 또는 특정 학과)를 지정하면 통합 메인과 해당 학과 게시판에 함께 표시됨
  - **공통 질문**: 모든 학과의 로그인 회원이 제2공학관 공용 시설·열람실 관련 질문 작성 가능
- **통합 메인 및 다중 필터·검색 (`/`)**:
  - 상단 요약 대시보드: `2공학관 공통 중요 공지`, `내 학과 공지사항`, `최근 등록된 질문` 한눈에 표시
  - 전체 글 모아보기에서 각 글에 `[컴전과]`, `[공지]`, `[질문]` 구분 배지 표시
  - **통합 검색(제목·내용·작성자)** + **학과 필터** + **글 종류(공지/질문) 필터** + **질문 상태 필터** 조합 검색 지원
- **질의응답 및 3단계 질문 해결 상태 구분**:
  - **답변 대기 (`WAITING`)**: 아직 답변이 달리지 않은 질문
  - **답변 등록 (`ANSWERED`)**: 질문에 댓글·답변이 달리면 자동으로 `답변 등록` 상태로 전환
  - **해결 완료 (`RESOLVED`)**: 질문 작성자 본인이 직접 `[질문을 해결 완료 상태로 변경]` 버튼을 눌러 완료 처리 (추가 질문 필요 시 `[해결 완료 취소]`로 다시 미해결 전환 가능)
  - **공식 답변 표시 (`★ 공식 답변`)**: 해당 공간 관리자가 작성한 답변에 공식 답변 배지 자동 부여
  - **본인 답변 수정·삭제**: 자신이 작성한 댓글·답변만 인라인 수정·삭제 가능

### [4단계] 첨부파일, 알림, 마이페이지 및 신고·회원·운영 관리 구현
- **첨부파일 업로드·교체 및 권한 검사**:
  - 공지·질문 작성 및 수정 시 문서·이미지 파일 첨부 및 기존 파일 삭제·교체 지원
  - **업로드 제한**: 게시글당 **최대 3개**, 파일당 **최대 2MB**, 허용 확장자(`.pdf, .txt, .png, .jpg, .jpeg, .gif, .zip, .docx, .xlsx, .pptx, .hwp, .csv`) 초과 시 업로드 즉시 차단
  - **다운로드 권한 검사 (`/api/attachments/[id]`)**: 숨김 처리된 게시글의 첨부파일은 원문 조회 권한(작성자 또는 담당 관리자)이 없는 사용자가 요청할 경우 `403`으로 다운로드 차단
- **새 답변 알림 및 알림함 (`/notifications`)**:
  - 내 질문에 답변이 등록되면 질문 작성자에게 **새 답변 알림(`Notification`)** 자동 생성
  - 상단 헤더에 읽지 않은 알림 개수 배지 실시간 표시
  - 알림함에서 **읽지 않은 알림(`새 알림`)과 읽은 알림(`읽음`) 구분**, 개별/전체 읽음 처리 및 클릭 시 해당 원문 게시글로 즉시 이동
- **마이페이지 및 비밀번호 변경 (`/mypage`)**:
  - **내 정보 조회**: 이름, 아이디, 소속 학과, 역할, **계정 상태(정상 이용 / 이용 제한 중 및 사유)** 확인
  - **내가 쓴 글**, **내가 쓴 댓글·답변(원문 바로가기 포함)**, **내 미해결 질문** 탭별 모아보기
  - **비밀번호 변경**: 현재 비밀번호 확인 후 새 비밀번호로 안전하게 변경
- **게시글·댓글 신고 및 관리자 운영 센터 (`/admin`)**:
  - 게시글 상세 화면에서 **게시글 신고** 및 **댓글 신고**(사유 입력) 접수
  - **신고 목록·처리**: 관리자가 신고 내역을 확인하고 `접수(PENDING)` · `검토 중(REVIEWING)` · `완료(RESOLVED)` · `반려(REJECTED)` 상태 및 처리 메모 관리
  - **게시물 숨김·삭제 사유 기록**: 관리자가 게시물을 숨김 또는 삭제할 때 조치 사유를 기록
  - **회원 조회 및 이용 제한**: 이름·아이디·학과로 회원을 검색하고, 문제 회원의 **이용 제한(기간·사유 지정) 및 해제** 처리
  - **이용 제한 계정 작성 차단**: 이용 제한 상태인 계정이 게시글이나 댓글 작성을 요청하면 서버에서 `403`으로 즉시 차단
  - **운영 현황 요약 및 관리자 처리 이력 (`AuditLog`)**: 전체 게시글, 미답변 질문, 미처리 신고 건수, 이용 제한 회원 수 요약 및 **누가 언제 어떤 관리 작업을 했는지(처리 이력)** 투명하게 기록
- **모바일 반응형 대응**: 휴대전화·태블릿 화면에서도 가로 스크롤 네비게이션 바와 반응형 테이블로 조회·작성·답변 가능

## 2. 프로젝트 실행 및 데이터베이스 초기화 방법

터미널(PowerShell 또는 CMD)에서 아래 명령어를 순서대로 실행합니다.

```bash
# 1. 패키지 설치 (최초 1회)
npm.cmd install

# 2. SQLite 데이터베이스 스키마 반영
npx.cmd prisma db push

# 3. 실습용 기본 계정 및 1~4단계 샘플 데이터 시드 생성
node prisma/seed.mjs

# 4. 개발 서버 실행 (http://localhost:3000)
npm.cmd run dev
```

## 4. 주요 화면 경로 안내

- **통합 메인 및 전체 글·검색·필터**: `/` (`/?board=ALL`, `/?board=COMMON`, `/?board=COMP`, `/?board=AERO`, `/?board=MECHA`, `/?board=INFO`)
- **게시글·질문·공지 작성 (첨부파일 포함)**: `/complaints/new`
- **게시글 상세·첨부 다운로드·질의응답·신고**: `/complaints/[id]`
- **게시글 수정 및 첨부파일 교체**: `/complaints/[id]/edit`
- **마이페이지 (내 글·내 답변·미해결 질문·비밀번호 변경)**: `/mypage`
- **알림함 (새 답변 알림 조회 및 읽음 처리)**: `/notifications`
- **관리자 센터 (운영 현황·신고 처리·게시물 관리·회원 이용 제한·관리자 처리 이력)**: `/admin`
